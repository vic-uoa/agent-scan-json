# 扫描对象与报告契约

## 落盘边界

单次扫描只写入一份最终 HTML：

```text
<报告根目录>/
└─ <上传工作流文件名>/
   └─ <上传工作流文件名>-安全扫描报告.html
```

目录名取 DSL 文件名去除扩展名后的值，并替换 Windows 非法路径字符。扫描 ID、随机 UUID 和工作流内部 ID 不参与目录命名。

以下对象只在扫描进程内存中流转，不得写为 JSON、Markdown、SVG 或截图文件：

| 内存对象 | 用途 |
|---|---|
| Workflow IR | 规范化节点、边、变量、工具、画布坐标与覆盖缺口 |
| Security facts | 确定性证据 |
| Semantic inventory | 入口、资产、边界、能力和逐节点审核维度 |
| Rule candidates | 聚合前原始匹配与候选 |
| Test cluster | 正例、反例、边界、变形和规则定向输入 |
| Model advisory | 接受/拒绝的惰性建议和非权威措辞 |
| Verification | 引用、聚合和输入簇校验 |
| Findings | 权威风险项 |
| Attack surface | 入口、资产、能力和攻击路径 |
| Quality gate | 风险门禁、扫描完整性、阻断项和覆盖缺口分类 |
| Report model | 汇总、可视化输入和最终 HTML 内容 |

解析器拥有节点、字段、边、变量和位置事实；规则引擎独占 Finding、状态、严重度、置信度和门禁；确定性输入簇构建器拥有种子血缘和最低用例覆盖。模型只能通过 `schemas/model-advisory.schema.json` 提交附加惰性测试、复核问题和非权威措辞。未知引用、真实密钥、重复输入和 Finding/目标不匹配的建议会被拒绝。

## HTML 报告契约

最终 HTML 必须：

- 自包含所有 CSS、JavaScript 和 SVG，不依赖网络资源；
- 先展示风险门禁、最高风险程度、扫描完整性和关键数量；
- 将原始 DSL 转换为完整工作流图；有画布坐标时保留原布局，没有坐标时使用可重复的分层拓扑布局；
- 用业务节点标题作为主要图形标签，节点 ID 仅保留在可展开的技术证据中；
- 将每项风险与其判定依据、修复建议和聚焦逻辑链 SVG 就地绑定；
- 条件分支显示可读的条件/否则标签，而不是只显示 source handle 或节点 ID；
- 支持按类别、严重度和证据状态筛选，并在键盘、窄屏、打印和减少动画偏好下保持可用；
- 对所有来自 DSL、规则和模型顾问的字符串做 HTML/SVG 转义。

风险门禁、扫描完整性和证据状态仍使用稳定英文枚举作为内部契约；HTML 只负责本地化展示。计划覆盖、路径可满足覆盖和真实执行覆盖必须分别计算，任何未执行测试都不得改变 Finding。
