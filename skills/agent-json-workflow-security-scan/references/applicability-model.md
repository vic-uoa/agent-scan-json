# Rule Applicability and False-Positive Control

安全库以“适用性优先”运行。规则数量和节点覆盖不允许代替适用性判断。

## 五道确定性门

一条规则只有依次通过以下门槛才能形成 `risk`：

1. **能力相关性**：节点具备规则针对的能力，例如网络读取、网络写入、模型推理、知识检索、动态执行或高信任输出。
2. **类型化路径**：需要跨节点影响时，必须存在明确的数据路径或控制路径。数据引用不能冒充可执行控制路径，画布连线也不能冒充参数污染。
3. **缺失控制**：只检查与当前能力和路径匹配的控制；固定目标、结构化 Schema、必经授权门、固定单数据集等确定性事实可以排除规则。
4. **合理影响**：区分人工展示、模型文本、外部读取、副作用写入、高影响动作和敏感数据外传。没有副作用或高信任消费时不得沿用高影响严重度。
5. **证据状态**：字段或路径事实可以确认，但业务影响或运行时条件未知时使用 `OBSERVED`、`PROBABLE` 或 `COVERAGE_GAP`，不能借缺失字段升级为 `CONFIRMED`。

## 路径类型

- `data path`：来自解析后的变量引用，只用于证明值、文本或模型输出如何传播。
- `control path`：来自工作流边，只用于证明节点的可执行先后关系和授权门是否必经。
- `mixed path`：只用于攻击面展示或一般可达性；不得单独证明参数受控或授权绕过。

授权绕过必须在控制图上同时证明“受保护路径”和“排除所有授权控制后仍存在的路径”。模型自由文本控制工具必须在数据图上证明模型输出绑定到工具参数。

## 影响层级

| 层级 | 示例 | 默认处理 |
|---|---|---|
| 本地结构 | 无效字段、重复句柄、无法解析的引用 | 确认配置事实；普通业务影响可归 posture |
| 人工可见 | 文本回答、普通只读 RAG | LOW/OBSERVED 或 hardening |
| 机器消费 | 条件判断、结构化下游、API 决策输出 | 至少验证 Schema；按下游影响调整 |
| 外部或副作用 | 网络调用、写操作、子工作流、Agent 工具 | 需要授权、参数约束、失败和供应链控制 |
| 高影响 | 支付、删除、权限、敏感数据外传、动态执行 | 可形成 HIGH/CRITICAL 和 FAIL 门禁 |

明确的数据类型冲突默认是本地配置事实，归入 `posture`；只有冲突位于机器消费、副作用或高影响路径并可能改变安全决策时，才升级为 `risk`。无法推断类型不等于类型冲突，应保留为未知或覆盖口径，不得猜测。

## 运行时缺口

运行时缺口只能在相关能力或后果路径已经成立后产生。例如：

- 普通文本模型不因未导出失败回退而逐节点报警；模型到达副作用能力后才检查。
- 固定单数据集不因 ACL 不在 JSON 中而逐节点报警；动态或敏感多数据集范围才适用。
- 工具输出没有 Schema 只有在进入模型、副作用工具或高信任输出时才适用。
- 同一运行时控制域的重复缺口按工作流聚合，但保留全部节点和原始匹配证据。

## 报告分组

- `risk`：安全影响相关事实或路径，进入风险数量和门禁。
- `posture`：JSON 特有配置与方言一致性观察。
- `hardening`：纵深防御和可靠性建议。
- `coverage_gap`：已适用规则仍缺少运行时事实。

质量输出使用两个正交维度：风险门禁只由 `risk` 驱动；扫描完整性把未知节点/字段/引用解析失败列为扫描器覆盖问题，把 IAM、网络、沙盒等 JSON 外事实列为运行时待补证。二者不得合并成一个 PASS/FAIL 结论。

每条规则必须在 `rules/rule-applicability.yml` 中恰好登记一次。新增或修改规则时，同时添加：危险正例、安全反例、确定性缓解、运行时缺口和路径类型回归测试。

## 0.2.0 语义约束

- `TOOL-004` 的代码能力本身归 posture；只有敏感参数为动态表达式时进入 risk。解释器、动态 SQL 与不安全反序列化以 HIGH/PROBABLE 报告，不把 AST 调用事实写成已证明的宿主逃逸或 CRITICAL 漏洞。
- 固定 SQL 的绑定参数、固定非解释器程序在 `shell=False` 下的数据 argv、SafeLoader、URL 固定 authority 下的动态路径/查询只排除相应注入判据，不证明运行时系统安全。
- 不可信性沿明确数据引用传播，CODE/结构节点不自动净化。字段选择器只继承选中的子树，敏感数据披露链必须从实际绑定的敏感字段开始，不允许源节点的其他敏感字段污染所有输出。
- 授权门必须使用动作相关的正向等值谓词；OR 的每个子条件都须成立为授权条件，AND 至少有一个授权条件。多条件缺少组合方式、否定比较、用户/模型输入的 approved、未解析引用、冲突句柄均不能抑制动作风险。
- 图搜索不静默截断长路径，故障串联使用控制路径。代码分析超预算或调用解析不完整必须形成 `TOOL-011` 和 INCOMPLETE。
- 密钥豁免仅作用于完整候选值，不作用于包含候选的整段文本。节点归属按 JSON Pointer 分隔符匹配，不能把索引 10 归给索引 1。

具体参考、证据格式、回归命令和能力边界见 [semantic-precision.md](semantic-precision.md)。
