# Node Security Review Matrix

该矩阵描述当前内部 JSON 方言的审核面。`静态`表示可由导出 JSON、IR 和图路径确定；`混合`表示静态检查已执行，但最终结论还需要平台或运行时事实。

| 原始节点 | 主要静态审核 | 必须保留为混合/运行时事实 |
|---|---|---|
| `HEAD` | 输入类型、必填、长度/数量/枚举、文件约束、敏感字段语义、入口引用 | 调用身份、真实数据分类、API 层额外 Schema |
| `MODEL` | Prompt 数据边界、输入来源、密钥字面量、输出结构、令牌预算、下游工具路径；只有到达副作用能力时检查失败回退 | 模型实际行为、系统 Prompt 注入方式、供应商侧护栏 |
| `AGENT` | MODEL 全部维度、目标/停止边界、工具数量和类型、动态高风险参数、知识+工具组合、动作路径 | 不可绕过停止开关、业务动作策略、实际工具权限 |
| `AI_PLUGIN` / `API_PLUGIN` | 方法、参数位置、动态 URL/资源 ID、输出 Schema、版本、明文密钥、可达数据流 | 注册表签名、服务端鉴权、对象级授权、出口代理 |
| `MCP` | MCP/工具标识、认证字段可见性、参数、方法、输出、版本和供应链 | MCP 服务端实现、Token 注入、工具列表漂移、租户隔离 |
| `WORKFLOW` | 子工作流 ID、输入输出契约、变量绑定、失败/副作用链 | 被调版本内容、委派身份、事务和补偿语义 |
| `NEW_KNOWLEDGE` | 数据集固定、检索数量、相关性阈值、来源传播、模型/Agent 数据流；固定单数据集只读 RAG 不机械产生 ACL 风险 | 数据集 ACL、租户过滤、内容净化、索引污染状态 |
| `CODE` | 语言、Python AST 语法、动态执行、进程、网络、文件原语、输入引用、明确返回类型与 `outputType` 一致性；缺少局部输出 Schema 仅在到达副作用或无下游契约时成项 | 动态返回类型、运行时沙盒、依赖包、系统调用拦截、网络/文件挂载 |
| `JUDGE` | 条件变量、操作符、`handleId/sourceIndex`、缺失和重复分支、到高影响动作路径；支持分支序号到 `handleId` 的映射 | 业务授权语义；模型判断不能替代确定性授权 |
| `LOOP` | 唯一入口/输出、内部可达性、循环输入输出、终止/预算字段 | 平台全局步数、总时限、并发和外部熔断 |
| `TEMPLATE` | 最终字段 Schema、重复/空字段、敏感数据路径、富文本/流式输出 | 前端渲染器净化、受众权限、外部传输策略 |
| `INTERMEDIATE_OUTPUT` | 结构化输出、历史消息变量、额外披露边界 | 受众、日志落盘、脱敏和保留策略 |
| `LOOP_START` / `LOOP_OUTPUT` | 拓扑、容器归属、循环输入输出契约 | 无独立业务能力，不作为未知工具报告 |

## 准确率口径

- 节点类型覆盖率：已观察节点中进入显式类型契约的比例。
- 节点字段覆盖率：已观察字段中进入版本化字段契约的比例。新增未知字段会产生 `unmapped_node_field`，不会被静默忽略。
- 变量解析覆盖率：成功绑定的引用占“成功绑定 + 空值/歧义/无法解析引用”的比例。
- 数据契约一致性：输出别名和嵌套字段路径解析后，生产者/消费者显式类型是否兼容；它是配置一致性检查，不等同于可利用漏洞。
- 规则检出率、误报率和漏报率只能通过带人工真值标签的多工作流基准集计算，不能由单个完整样例或规则数量推导。
- `COVERAGE_GAP` 不是漏洞；报告区分扫描器未理解 JSON 的覆盖问题与 JSON 本身不包含的运行时待补证。
- 风险数量只计算 `report_group=risk`；`posture`、`hardening` 和 `coverage_gap` 分别报告。

每个节点的实际审核维度、Finding 和覆盖缺口写入 `03-semantic-inventory.json.security_coverage.node_reviews`，汇总比例写入 `report.json.security_coverage`。
